# Kaz-MAGE: Cross-Domain & Wild Data Benchmark for Kazakh AI Text Detection
**Design Specification**  
**Date**: September 9, 2026  
**Status**: Approved (Brainstorming & Design Phase)  
**Target Branch**: `feat/kaz-mage-cross-domain`  

---

## 1. Motivation & Background

Existing evaluations of AI text detectors in the Kazakh language have been restricted almost exclusively to conversational consumer reviews (e.g., Kaspi e-commerce reviews). Reviews feature short character lengths ($L \le 85$ characters), colloquial syntax, and heavy code-switching. In real-world deployment, however, detectors must evaluate multi-paragraph expository essays, formal journalistic news reports (*Informburo*, *Tengrinews*, *Kazinform*), and encyclopedic articles (*Kazakh Wikipedia*).

Following the **MAGE protocol** (Li et al., ACL 2024: *"MAGE: Machine-generated Text Detection in the Wild"*), this specification establishes the first multi-domain, multi-generator benchmark for the Kazakh language, evaluating models across a full $2 \times 2$ matrix:
$$\text{Generators } \{\text{Seen}, \text{Unseen}\} \times \text{Domains } \{\text{Seen}, \text{Unseen}\}$$

Furthermore, we evaluate whether our dual-stream architecture (`MorphoContrastiveDetector`) with gated cross-attention fusion dynamically shifts its routing gate $\mathbf{g}$ between the semantic stream and the morphological stream when transitioning from short conversational reviews to long-form formal prose.

---

## 2. The Kaz-MAGE $2 \times 2$ Evaluation Matrix

The benchmark evaluates six model variants across four quadrants:

| Quadrant | Setting Name | Generator Class | Domain Class | Description & Test Slices |
| :--- | :--- | :--- | :--- | :--- |
| **Q1** | **In-Distribution (ID)** | Seen (`Sherkala-7B`) | Seen (`Reviews`) | Consumer reviews generated by Sherkala ($N=1{,}000$ paired) |
| **Q2** | **OOD-Generator** | Unseen (`Qwen-2.5-7B`) | Seen (`Reviews`) | Consumer reviews generated by Qwen-2.5 ($N=1{,}000$ paired) |
| **Q3** | **OOD-Domain** | Seen (`Sherkala-7B`) | Unseen (`News` & `Wiki`) | Formal news and Wikipedia articles generated by Sherkala ($N=1{,}000$ paired) |
| **Q4** | **Wild OOD (Hardest)** | Unseen (`Qwen-2.5-7B`) | Unseen (`News` & `Wiki`) | Formal news and Wikipedia articles generated by Qwen-2.5 ($N=1{,}000$ paired) |

## 3. Dataset Construction & Generation Pipeline

### 3.1. Human Ground Truth Collection ($y = 0$)
1. **Kazakh News ($N=500$)**:
   * Sourced from authentic Kazakh news outlets (*Informburo*, *Tengrinews*, *Kazinform*) spanning politics, economics, science, sports, and culture.
   * Format: Paragraphs of $150 \text{--} 350$ words ($\approx 1{,}000 \text{--} 2{,}500$ characters).
2. **Kazakh Wikipedia ($N=500$)**:
   * Curated from verified Kazakh Wikipedia articles spanning history, geography, biographical entries, and natural sciences.
   * Format: Coherent lead and section paragraphs ($150 \text{--} 350$ words).
3. **Consumer Reviews ($N=1{,}000$)**:
   * Sourced from human Kaspi reviews in `data/seed_human_reviews_1k.json` ($L \le 85$ chars).

### 3.2. Machine Text Generation via Prefix Continuation ($y = 1$)
To isolate generator syntax from topical bias, all synthetic texts follow the **Prefix Continuation** paradigm:
* **Prefix Prompt**: For each human article, the title/headline and the first $20$ words are extracted as the fixed prompt prefix:
  $$\text{Prefix} = [\text{Title}] + \text{" "} + \text{Words}_{1:20}$$
* **Generation**: The LLM is conditioned on this prefix to generate the continuation of the article ($150 \text{--} 350$ words).
* **Length Matching**: Each generated sample is constrained to match the character and word length distribution of its human counterpart ($\pm 15\%$).
* **Generators**:
  * **Seen LLM**: `Sherkala-7B` (or `KazLLM-7B-Instruct`), representing generators observed during training.
  * **Unseen LLM**: `Qwen-2.5-7B-Instruct`, representing modern zero-shot wild generators.

### 3.3. Dataset Schema (`data/kaz_mage_eval_6k.json`)
```json
{
  "id": "mage_news_qwen_001",
  "domain": "news",
  "generator": "Qwen-2.5-7B-Instruct",
  "is_unseen_domain": true,
  "is_unseen_generator": true,
  "quadrant": "Q4",
  "prefix": "Қазақстанда жаңа цифрлық білім беру...",
  "text": "Қазақстанда жаңа цифрлық білім беру платформасы іске қосылды. Бұл жүйе оқушыларға...",
  "label": 1,
  "char_length": 1420,
  "word_count": 215
}
```
* Total dataset size: $6{,}000$ evaluation instances ($3{,}000$ Human, $3{,}000$ AI across 3 domains $\times$ 2 generators).

## 4. Architectural Enhancements for Long-Form Expository Text

### 4.1. Sequence Length & Positional Embeddings
1. **Positional Embedding Extension**:
   * In `models/morpho_contrastive_detector.py`, extend `MorphemeEncoder.pos_embedding` from $256 \to 512$ with defensive clamping:
     $$\text{pos\_ids} = \min(\text{pos\_ids}, 511)$$
2. **Tokenizer Batch Encoding**:
   * In `api/morpheme_tokenizer.py`, update `batch_encode(texts, max_length=256)` (configurable up to $512$).
3. **Semantic Stream Alignment**:
   * Set KazRoBERTa subword tokenizer max sequence length to $256$ (or $512$), maintaining dimensionality match $\mathbf{h}_{\text{sem}}, \mathbf{h}_{\text{morph}} \in \mathbb{R}^{B \times 768}$.

### 4.2. Sentence-Boundary FST Parsing
* Ensure `AdvancedKazakhFSTAnalyzer` processes multi-sentence paragraph punctuation without memory leaks or buffer truncation.

## 5. Evaluation Protocol & Metrics

### 5.1. Performance Metrics
For each of the six models across each quadrant:
1. **ROC-AUC** (primary threshold-independent ranking metric).
2. **Youden's $J$ Calibrated Metrics**: Optimal threshold $\tau^* = \arg\max (\text{TPR} - \text{FPR})$, reporting Accuracy, Macro F1, Precision, and Recall at $\tau^*$.
3. **Domain Degradation Rate**:
   $$\Delta \text{AUC}_{\text{domain}} = \text{AUC}_{\text{Q1}} - \text{AUC}_{\text{Q3}}$$
   $$\Delta \text{AUC}_{\text{wild}} = \text{AUC}_{\text{Q1}} - \text{AUC}_{\text{Q4}}$$
4. **Bootstrap 95% Confidence Intervals**: $B=1{,}000$ iterations with replacement.

### 5.2. Dynamic Gate Routing Analysis ($\mathbf{g}$)
The gating weight $\mathbf{g} \in [0, 1]$ represents the semantic stream contribution ($\mathbf{h}_{\text{fused}} = \mathbf{g} \odot \mathbf{h}_{\text{sem}} + (1 - \mathbf{g}) \odot \mathbf{h}_{\text{morph}}$).
* We record and report $\bar{g}_{\text{reviews}}$, $\bar{g}_{\text{news}}$, and $\bar{g}_{\text{wiki}}$.
* **Hypothesis**: In informal conversational text, morphological affix tampering provides strong discriminative signal ($g \approx 0.45$). In formal journalistic Kazakh with rigid agglutinative grammar, the gate will dynamically adapt, increasing reliance on discourse-level semantics ($g \to 0.70$).

## 6. Models Evaluated in the Benchmark
1. **Model 1 (`KazRoBERTa Pure`)**: Baseline single-stream KazRoBERTa trained with Cross-Entropy on raw text.
2. **Model 2 (`KazRoBERTa Hybrid FST`)**: Single-stream KazRoBERTa trained on FST-segmented morpheme text.
3. **Model 3 (`KazRoBERTa + SupCon`)**: Single-stream KazRoBERTa trained with multi-task SupCon + CE.
4. **Model 4 (`Dual-Stream CE-Only`)**: Dual-stream architecture with gated fusion trained only with Cross-Entropy ($\lambda_{\text{supcon}} = 0$).
5. **Model 5 (`Morpho-SupCon Full`)**: Dual-stream architecture with gated fusion and multi-task Supervised Contrastive Loss ($\lambda_{\text{supcon}} = 0.5$).
6. **Model 5-Adv (`Invariant Contrastive Defense`)**: Dual-stream architecture with multi-task SupCon + Latent Invariance Loss ($\mathcal{L}_{\text{inv}}$) trained under adversarial perturbations.
