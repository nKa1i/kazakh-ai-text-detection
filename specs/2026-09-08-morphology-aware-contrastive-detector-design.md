## 1. Executive Summary & Problem Formulation

Standard fine-tuned transformer detectors (such as KazRoBERTa) trained on single-generator distributions suffer catastrophic performance degradation when exposed to modern, unseen Large Language Models. In our diagnostic stress-test ($N = 2,000$ paired samples), standard `KazRoBERTa (Pure)` collapsed from **96.10% in-distribution accuracy** down to **36.75%** on text generated by `Qwen-2.5-7B-Instruct`, exhibiting an alarming **49.8% False Positive Rate** on real human reviews and a **76.7% False Negative Rate** on synthetic text.

This failure stems from two interconnected structural flaws:
1. **Surface Artifact Overfitting:** Standard Cross-Entropy training latches onto superficial lexical patterns of the training generator (Sherkala-7B) rather than learning invariant properties of synthetic text.
2. **Agglutinative Subword Fragmentation:** Low-resource agglutinative languages like Kazakh stack multiple grammatical suffixes onto stems. Uncontrolled BPE tokenization fragments these morphemes unpredictably (token inflation up to 4.64 tokens/word), misleading the classifier on short texts ($\le 60$ characters).

To overcome this dual challenge, this specification defines the **Morphology-Aware Contrastive Detector (`Morpho-SupCon KazRoBERTa`)**, directly implementing the core innovations outlined in Topics 1 & 2 of our MSc Thesis Proposal.

## 3. System Architecture

The architecture decouples semantic comprehension from morphological grammar, processing each input through two parallel streams before dynamic gated fusion:

```
                      Raw Kazakh Text
                             │
            ┌────────────────┴────────────────┐
            ▼                                 ▼
   [ Stream 1: Semantic ]           [ Stream 2: Morphology ]
   KazRoBERTa Contextual Base       Rule-Based FST Decomposition
   (kz-transformers)                (AdvancedKazakhFSTAnalyzer)
            │                                 │
   Token Embeddings + Pooling       Morpheme Sequence Tokens ($V_M \approx 250$)
            │                                 │
            │                       Lightweight Bi-Transformer (2 layers)
            │                                 │
            ▼                                 ▼
   h_sem ∈ ℝ^{768}                  h_morph ∈ ℝ^{768}
            │                                 │
            └───────────────┬─────────────────┘
                            ▼
               [ Gated Cross-Attention Fusion ]
                     g = σ(W_g [h_sem; h_morph] + b_g)
               h_fused = g ⊙ h_sem + (1 - g) ⊙ h_morph
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
     [ Classification Head ]    [ Projection Head ]
     Linear(768 → 2)            MLP(768 → 256 → 128)
     Cross-Entropy Loss (L_CE)  Supervised Contrastive Loss (L_SupCon)
```

### 3.1 Stream 1: Semantic Representation
* **Base Model:** Pretrained `kz-transformers/kaz-roberta-conversational` (6 layers, 12 heads, 768 hidden dimension, 52,000 BPE vocabulary).
* **Input:** Raw Kazakh text tokens with standard `<s>` and `</s>` boundaries.
* **Output:** Contextual semantic sentence embedding $\mathbf{h}_{\text{sem}} \in \mathbb{R}^{768}$ obtained via pooled output of the sequence.

### 3.2 Stream 2: Explicit Morphology Representation
* **Decomposition Engine:** `AdvancedKazakhFSTAnalyzer` (from `fst_analyzer.py`), implementing finite-state segmentation of:
  * Nominal case affixes (24 distinct allomorphs).
  * Possessive markers (24 allomorphs).
  * Plural markers (6 allomorphs).
  * Verbal tense, participles, and converbs (25 suffixes).
  * Code-switched Russian commercial loanword roots with Kazakh inflections.
* **Morpheme Vocabulary ($V_M \approx 250$):**
  * Closed vocabulary comprising canonical Kazakh affix tags, grammatical category indicators (`<STEM>`, `<LOAN>`, `<PLUR>`, `<CASE>`, `<POSS>`, `<VERB_TENSE>`, `<VERB_AGR>`), and boundary markers.
* **Morphology Encoder:**
  * 2-layer Bidirectional Transformer Encoder ($d_{\text{model}} = 768$, 8 heads, $d_{\text{ff}} = 1536$).
  * Pools the morpheme sequence into $\mathbf{h}_{\text{morph}} \in \mathbb{R}^{768}$.

### 3.3 Dynamic Gated Fusion & Design Rationale
Rather than naive vector concatenation or brittle token-level alignment, the two representations interact via a learnable gating vector $\mathbf{g} \in [0, 1]^{768}$:
$$\mathbf{g} = \sigma\left(\mathbf{W}_g [\mathbf{h}_{\text{sem}}; \mathbf{h}_{\text{morph}}] + \mathbf{b}_g\right)$$
$$\mathbf{h}_{\text{fused}} = \mathbf{g} \odot \mathbf{h}_{\text{sem}} + (\mathbf{1} - \mathbf{g}) \odot \mathbf{h}_{\text{morph}}$$

#### Why Sentence-Level Gated Fusion Instead of Token-Level Cross-Attention?
In agglutinative Kazakh, a single word such as *«жазбаларыңыздан»* produces:
* **1 whitespace word**,
* **4 morphological units** (*жазба + лар + ыңыз + дан*),
* **3 arbitrary BPE subwords** (*жаз + балары + ңыздан*).

Attempting token-by-token alignment forces an artificial mapping between incompatible BPE and morphemic boundaries, introducing alignment noise. Sentence-level pooled gated fusion abstracts away this length mismatch, allowing the gate $\mathbf{g}$ to shift weight toward $\mathbf{h}_{\text{morph}}$ on short reviews ($\le 60$ characters) where semantic context is sparse, and toward $\mathbf{h}_{\text{sem}}$ on long texts.

## 4. Multi-Task Training Objective & Dual-View Augmentation

To prevent the model from overfitting to generator-specific surface lexical patterns, training optimizes a multi-task objective with dual-view contrastive augmentation:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \lambda \mathcal{L}_{\text{SupCon}}$$

### 4.1 Dual-View Positive Pair Construction
Following `da_lei_content.txt` (Line 18), for each sample $x_i$ in mini-batch $N$, we generate two complementary views:
1. **View A ($x_i^A$):** Original text input.
2. **View B ($x_i^B$):** Morphologically regularized text (FST segmented with stochastic morpheme dropout $p=0.05$ or synonym root replacement).

This creates an augmented batch of $2N$ samples where each review has an intrinsic positive partner $(i, i')$ invariant to surface formatting, in addition to label-sharing peers in $P(i)$.

### 4.2 Supervised Contrastive Loss ($\mathcal{L}_{\text{SupCon}}$)
Each fused representation $\mathbf{h}_{\text{fused}, i}$ is mapped to a normalized latent vector $\mathbf{z}_i = \text{Normalize}(\text{MLP}(\mathbf{h}_{\text{fused}, i})) \in \mathbb{R}^{128}$:

$$\mathcal{L}_{\text{SupCon}} = \sum_{i \in I} \frac{-1}{|P(i)|} \sum_{p \in P(i)} \log \frac{\exp(\mathbf{z}_i \cdot \mathbf{z}_p / \tau)}{\sum_{a \in A(i)} \exp(\mathbf{z}_i \cdot \mathbf{z}_a / \tau)}$$

* **Positive Set $P(i)$:** All instances sharing the ground-truth label ($y_i = y_p$). Real human reviews cluster together; synthetic reviews from all generators cluster into an invariant machine-generated manifold.
* **Negative Set:** Instances from opposing classes ($y_i \neq y_a$).
* **Temperature:** $\tau = 0.07$.

### 4.3 Supervised Classification Loss ($\mathcal{L}_{\text{CE}}$)
Standard binary cross-entropy on class logits from the linear head:
$$\mathcal{L}_{\text{CE}} = - \frac{1}{2N} \sum_{i=1}^{2N} \left[ y_i \log \hat{y}_i + (1 - y_i) \log (1 - \hat{y}_i) \right]$$

### 4.4 Hyperparameters
* Balancing parameter: $\lambda = 0.5$ (with cosine decay after epoch 2).
* Optimizer: AdamW ($\text{lr}_{\text{backbone}} = 2\times 10^{-5}$, $\text{lr}_{\text{morph}} = 1\times 10^{-4}$, weight decay = $0.01$).
* Batch size: 32 (effective batch size 64 via gradient accumulation).
* Training epochs: 4 with linear warmup over the first 10% steps.

## 6. Evaluation Metrics & Systematic Ablation Plan

### 6.1 Evaluation Suite (Top-Tier Standard)
1. **Threshold-Independent Representation Metric:**
   * **ROC-AUC (Area Under the Receiver Operating Characteristic Curve):** Quantifies separability across all possible decision thresholds.
   * **Equal Error Rate (EER):** The operating point where $\text{FPR} = \text{FNR}$.
   * **Optimal Threshold ($\tau^*$ via Youden’s J):** $J = \text{Sensitivity} + \text{Specificity} - 1$.
2. **Fixed Threshold ($p = 0.5$) Metrics:**
   * Accuracy, Macro F1-Score, Precision, Recall.
   * False Positive Rate (FPR) and False Negative Rate (FNR).
3. **RAID-Compliant Length Granularity:**
   * Stratified strictly across Short ($\le 60$ chars), Medium ($61\text{--}85$ chars), and Long ($> 85$ chars).
4. **Statistical Hypothesis Testing:**
   * McNemar’s test with Edwards’ continuity correction on short-text false accusations ($\chi^2, p$-value).
   * 1,000-iteration Bootstrap 95% Confidence Intervals for all metrics.
5. **Inference Latency & Efficiency:**
   * Throughput (samples/sec) and latency (ms/sample) on CPU and GPU to confirm real-time deployability.

### 6.2 5-Stage Ablation Matrix
1. **`KazRoBERTa (Pure)`**: Single-stream, CE loss only, raw text (Baseline).
2. **`KazRoBERTa (Hybrid FST)`**: Single-stream, CE loss only, FST pre-segmented text (Baseline).
3. **`KazRoBERTa + SupCon (Single Stream)`**: Single-stream with Supervised Contrastive Loss (Ablation: Contrastive effect alone).
4. **`Dual-Stream KazRoBERTa (CE Only)`**: Dual-stream architecture with Cross-Entropy only (Ablation: Morphological fusion alone).
5. **`Morpho-SupCon KazRoBERTa (Full Method)`**: Complete dual-stream architecture with multi-task SupCon + CE objective.
