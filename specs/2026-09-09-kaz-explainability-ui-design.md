## 1. Executive Summary & Objective

Building upon the **Kaz-DocumentEngine** (Step 2), this specification defines the interactive inspection and explainability web application for the Kazakh AI Text Detector.

The application allows researchers, educators, and users to:
1. Input arbitrary Kazakh text (reviews, student essays, news articles, academic theses) via textarea or file upload (`.txt`, `.docx`, `.pdf`).
2. Run one-click benchmark demonstration samples across all experimental quadrants.
3. View executive document metrics: three-tier verdict (`"Authentic Human"`, `"Partially AI / Hybrid"`, `"Machine-Generated"`), overall calibrated AI probability, volume-weighted AI content ratio, and worst-chunk attribution.
4. Inspect an interactive **Document Heatmap** where every sentence is color-highlighted based on machine generation risk with full XSS escaping.
5. Click or select any sentence to open an **Explainability Diagnostic Card** revealing:
   - Sentence AI probability.
   - Dynamic Fusion Gate distribution ($\mathbf{g}$ Semantic Weight vs. $1 - \mathbf{g}$ Morphological Weight).
   - Word-by-word Finite State Transducer (FST) morphological analysis (root stem, affix chains, part-of-speech tags).

### 2.1 File & Module Responsibilities

1. **`ui/app.py`**:
   - Main entrypoint launched via `python ui/app.py`.
   - Assembles the Gradio Blocks interface.
   - Hosts demo preset texts and handles file upload parsing.
2. **`ui/highlighting.py`**:
   - HTML/CSS rendering engine for sentence highlighting.
   - Enforces strict `html.escape()` sanitization to prevent XSS injection.
   - Color coding mapped to calibrated threshold $\tau^* = 0.9980$:
     - Green ($p < 0.25$): Authentic Human.
     - Amber ($0.25 \le p < \tau^*$): Moderate Risk / Transition.
     - Red ($p \ge \tau^*$): Machine-Generated.
   - Generates interactive spans with `onclick` and data attributes.
3. **`ui/file_loader.py`**:
   - Defensive document reader supporting `.txt`, `.docx` (via `python-docx` if present), and `.pdf` (via `pypdf` if present).
   - Includes graceful fallbacks when optional PDF/Word libraries are not installed.
   - Enforces maximum file size (10 MB) and word cap (25,000 words).
4. **`ui/presets.py`**:
   - Stores 6 authentic pre-configured Kazakh text samples:
     1. `kaspi_review_human`: Authentic colloquial product review.
     2. `news_human`: Formal journalistic article (*Tengrinews* / *Kazinform*).
     3. `wikipedia_human`: Academic encyclopedic article (*kk-wiki*).
     4. `sherkala_ai`: Formal article generated by `Sherkala-7B`.
     5. `qwen_wild_ai`: Unseen generator wild article by `Qwen-2.5-7B`.
     6. `hybrid_student_essay`: Authentic human essay containing an injected AI paragraph.

## 3. Security & Robustness Constraints

1. **XSS / HTML Injection**: All text rendered into `gr.HTML` components must pass through `html.escape()` prior to string interpolation.
2. **DoS & Memory Protection**:
   - Max file size: `10 MB`.
   - Max document length: `25,000 words`.
3. **Dual Interactive Navigation**:
   - Visual heatmap clickable spans coupled with a native Gradio Dropdown (`"Inspect Sentence #..."`) to guarantee 100% cross-browser reliability.
4. **Offline / Mock Mode**:
   - If model weights or CUDA GPUs are unavailable, `DocumentDetector` automatically operates with mock/CPU fallback, displaying an informational badge rather than crashing.
5. **Camera-Ready Paper Protection**:
   - Under no circumstances shall `aist2026/paper.tex` be touched or modified.
