# Kaz-MultiDomain: Tri-Domain Contrastive Training Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train the dual-stream Morpho-Contrastive Detector on a balanced Tri-Domain corpus (Reviews, News, Wikipedia) with cross-domain contrastive alignment, resolving the Q3 domain blindspot (improving ROC-AUC from $0.6449 \to \ge 0.9500$) while preserving $\ge 98\%$ conversational review detection and keeping Qwen-2.5-7B as a 100% unseen generator.

**Architecture:**
- `scripts/generate_multi_domain_train_dataset.py`: Generates the $6{,}000$-sample balanced tri-domain training dataset with automated SHA-256 isolation checks against the evaluation benchmark.
- `kaz_mage/sampler.py`: Stratified mini-batch sampler ensuring balanced domain representation per batch.
- `scripts/train_multi_domain.py`: Multi-task training loop integrating Cross-Entropy and Cross-Domain Supervised Contrastive Loss ($\mathcal{L}_{\text{SupCon}}$).
- `scripts/prepare_multi_domain_kernel.py`: Packages self-contained kernel for Kaggle Dual Tesla T4 execution and held-out Kaz-MAGE evaluation across Q1–Q4.

**Tech Stack:** Python 3.12, PyTorch, Transformers (`kz-transformers/kaz-roberta-conversational`), `AdvancedKazakhFSTAnalyzer`, Kaggle Dual Tesla T4 GPUs.

## Global Constraints
- Under no circumstances shall `aist2026/paper.tex` be touched or modified.

- `Qwen-2.5-7B-Instruct` must remain strictly unseen in the training dataset ($100\%$ of AI training data generated by `Sherkala-7B`).
- Automated SHA-256 check must confirm $0\%$ overlap between training and evaluation datasets.

```python
# tests/test_multi_domain_data.py
import unittest
import os
import json
import tempfile
from scripts.generate_multi_domain_train_dataset import (
    generate_multi_domain_train_dataset,
    audit_dataset_isolation
)

class TestMultiDomainData(unittest.TestCase):
    def test_mini_train_dataset_generation_and_balance(self):
        with tempfile.TemporaryDirectory() as tmpdir:
            train_out = os.path.join(tmpdir, "test_train_mini.json")
            # Create a small dummy eval dataset to test isolation audit
            dummy_eval = os.path.join(tmpdir, "dummy_eval.json")
            with open(dummy_eval, "w", encoding="utf-8") as f:
                json.dump([{"text": "Бұл тестілік бөлек мәтін.", "id": "eval_1"}], f)

            generate_multi_domain_train_dataset(
                output_path=train_out,
                eval_benchmark_path=dummy_eval,
                samples_per_domain=30,
                seed=42
            )
            self.assertTrue(os.path.exists(train_out))

            with open(train_out, "r", encoding="utf-8") as f:
                data = json.load(f)

            # Check total count and domain balance
            self.assertEqual(len(data), 90)  # 30 * 3 domains
            domain_counts = {}
            for item in data:
                domain_counts[item["domain"]] = domain_counts.get(item["domain"], 0) + 1
                # Qwen should NEVER be in the training set
                self.assertNotEqual(item.get("generator"), "Qwen-2.5-7B-Instruct")
                self.assertEqual(item.get("generator"), "Sherkala-7B" if item["label"] == 1 else "human")

            self.assertEqual(domain_counts.get("consumer_reviews"), 30)
            self.assertEqual(domain_counts.get("news"), 30)
            self.assertEqual(domain_counts.get("wikipedia"), 30)

            # Audit isolation
            audit = audit_dataset_isolation(train_out, dummy_eval)
            self.assertTrue(audit["is_clean"])
            self.assertEqual(audit["overlap_count"], 0)

if __name__ == "__main__":
    unittest.main()
```
