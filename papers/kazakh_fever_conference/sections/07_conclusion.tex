\section{Conclusion}
\label{sec:conclusion}

In this paper, we introduced \textbf{Kazakh-FEVER 3K}, the first human-validated, morphologically-grounded fact verification benchmark for Kazakh, comprising 3,000 annotated claim-evidence pairs. To eliminate superficial lexical heuristics, we formulated the Hard NEI protocol, systematically demanding fine-grained morphological reasoning over negation, evidentiality, and modality markers. 

To address agglutinative sparsity, we developed a hybrid retrieval pipeline combining morpheme-stemmed BM25 with dense multilingual representations via Reciprocal Rank Fusion, achieving 99.8\% Recall@5 over 250,000 Wikipedia chunks. Furthermore, we designed a morphological NLI verifier augmented with explicit 16-D affix features and a 2D Trust Matrix that jointly evaluates factual veracity and generative provenance. Our verifier achieves 82.6\% accuracy and 82.1\% Macro-F1 (+10.8\% over XLM-RoBERTa-base and +11.5\% on Hard NEI). Future work will extend this framework across Kipchak Turkic languages and incorporate multi-modal evidence streams.
