\chapter{Kazakh-FEVER 3K Benchmark Annotation Protocols and Corpus Schemas}
\label{app:fever_annotation}

This appendix provides the formal annotation guidelines, verification criteria, adversarial perturbation procedures, and JSON corpus schemas utilized in the creation of the \textbf{Kazakh-FEVER 3K} benchmark. The benchmark comprises 3,000 verified claim-evidence pairs evaluated against a 250,000-passage encyclopedic knowledge corpus grounded in Kazakh Wikipedia, governmental archives, and cultural repositories.

\section{Gold Evidence Identification Guidelines}
\label{sec:app_fever_evidence_guidelines}

Annotators were tasked with identifying the minimal, sufficient set of encyclopedic sentences necessary to verify or refute a candidate factual claim.

\subsection{Core Principles of Evidence Selection}
\begin{enumerate}
    \item \textbf{Minimality Principle:} An evidence set $\mathcal{E}^* = \{s_1, s_2, \dots, s_k\}$ is minimal if removing any sentence $s_j \in \mathcal{E}^*$ renders the remaining sentences insufficient to determine the truth value of the claim $c$:
    \begin{equation}
    \forall s_j \in \mathcal{E}^*, \quad (\mathcal{E}^* \setminus \{s_j\}) \not\models c \quad \text{and} \quad (\mathcal{E}^* \setminus \{s_j\}) \not\models \neg c
    \end{equation}
    Annotators were strictly prohibited from highlighting entire paragraphs or redundant narrative framing.

    \item \textbf{Sufficiency Principle:} The identified evidence must logically entail or refute the claim without requiring unstated background assumptions or world knowledge beyond standard linguistic and arithmetic competence.

    \item \textbf{Single-Hop vs. Multi-Hop Evidence:}
    \begin{itemize}
        \item \textit{Single-Hop Evidence (72.4\% of benchmark):} A single declarative sentence contains all necessary entities, relations, and temporal anchors to determine claim veracity.
        \item \textit{Multi-Hop Evidence (27.6\% of benchmark):} Verifying the claim requires bridging across 2 or 3 sentences, either within the same encyclopedic article (co-reference bridging) or across hyperlinked articles (entity transfer). The maximum allowed evidence hop count was capped at 3 sentences.
    \end{itemize}
\end{enumerate}

\subsection{Document Boundary and Passage Normalization}
All source articles were pre-processed using the `SentencePreservingChunker` detailed in Chapter \ref{chap:morpho_contrastive_detection}, preserving Kazakh honorifics, abbreviations (e.g., \textit{ж.}, \textit{ғ.}, \textit{т.б.}, \textit{қ.}), and decimal numbers. Each passage was assigned a unique persistent identifier format:
\begin{equation}
\text{\texttt{doc\_id}} = \text{\texttt{KZWiki\_[ArticleTitle]\#s[SentenceIndex]}}
\end{equation}

\section{Three-Way Natural Language Inference Decision Protocols}
\label{sec:app_fever_decision_protocols}

Annotators categorized each claim-evidence pair into one of three mutually exclusive classes: \textsc{Supported}, \textsc{Refuted}, or \textsc{Not Enough Information} (NEI).

\subsection{Formal Decision Boundaries}
\begin{enumerate}
    \item \textbf{\textsc{Supported}:}
    \begin{itemize}
        \item The evidence directly affirms all propositions asserted in the claim.
        \item Valid paraphrasing, morphological re-casing, passive/active voice diathesis alternation, and exact synonym substitution are permitted, provided truth conditions remain invariant.
        \item \textit{Example:} Claim: \textit{``Қасым-Жомарт Тоқаев 1953 жылы туған''} (Kassym-Jomart Tokayev was born in 1953). Evidence: \textit{``Қасым-Жомарт Кемелұлы Тоқаев 1953 жылғы 17 мамырда Алматы қаласында дүниеге келген.''} $\implies$ \textsc{Supported}.
    \end{itemize}

    \item \textbf{\textsc{Refuted}:}
    \begin{itemize}
        \item The evidence directly contradicts at least one proposition in the claim.
        \item Contradiction classes include: (a) Polarity contradiction via verbal negation suffixes (\textit{-ма/-ме/-ба/-бе/-па/-пе}); (b) Numerical and quantitative discrepancies; (c) Conflicting temporal dates or historical eras; (d) Incompatible named entity roles or geographical misallocations.
        \item \textit{Example:} Claim: \textit{``Абай Құнанбайұлы 1840 жылы дүниеге келген''} (Abai Kunanbayuly was born in 1840). Evidence: \textit{``Абай (Ибраһим) Құнанбайұлы 1845 жылы 10 тамызда Шығыс Қазақстан облысында туған.''} $\implies$ \textsc{Refuted} (Temporal divergence: 1840 vs. 1845).
    \end{itemize}

    \item \textbf{\textsc{Not Enough Information (NEI)}:}
    \begin{itemize}
        \item The encyclopedic corpus neither verifies nor refutes the asserted proposition.
        \item \textit{Standard NEI:} The retrieved evidence mentions the main entity but makes no statement regarding the asserted predicate.
        \item \textit{Hard NEI (Adversarial):} The claim exhibits high lexical and semantic overlap with the evidence, yet asserts an unmentioned attribute, a speculative consequence, or an unverified evidential stance.
    \end{itemize}
\end{enumerate}

\section{Hard NEI Adversarial Synthesis Protocol}
\label{sec:app_fever_hard_nei_protocol}

Standard fact-checking benchmarks suffer from superficial lexical bias: models often predict \textsc{Supported} merely because the claim shares high word overlap with the retrieved passage. To counter this, our protocol enforces an adversarial synthesis pipeline generating 500 \textsc{Hard NEI} claims (constituting 50\% of the 1,000 NEI instances).

\subsection{Perturbation Transformation Operators}
Four systematic perturbation operators $\mathcal{T}_{\text{adv}}$ were applied to true encyclopedic sentences:
\begin{enumerate}
    \item \textbf{High-Overlap Entity Substitution ($\mathcal{T}_{\text{ent}}$):} Replace a peripheral entity or secondary location with a sibling entity drawn from the identical Wikidata taxonomic category (e.g., swapping \textit{Қарағанды} for \textit{Теміртау}), maintaining $>85\%$ unigram lexical overlap.
    \item \textbf{Temporal Drift ($\mathcal{T}_{\text{temp}}$):} Shift an unmentioned year or decade into a plausible historical interval where the corpus remains silent regarding the specific event.
    \item \textbf{Morphological Polarity Inversion with Lexical Compensation ($\mathcal{T}_{\text{polar}}$):} Flip a verbal negation morpheme (\textit{-ма/-ме}) while simultaneously substituting an antonymous root, creating a nuanced semantic distractor that defeats unigram negation counting.
    \item \textbf{Epistemic and Evidential Stance Mutation ($\mathcal{T}_{\text{evid}}$):} Convert a confirmed factual assertion into an unconfirmed rumor using the hearsay evidential suffix \textit{-ыпты/-іпті} and modal particles (\textit{деседі}, \textit{мүмкін}). Because the encyclopedia does not attest to the hearsay stance, the claim is strictly \textsc{NEI}.
\end{enumerate}

\section{Annotator Qualifications, Training, and Quality Assurance}
\label{sec:app_fever_quality_assurance}

\subsection{Annotator Demographics and Recruitment}
The annotation team consisted of eight native Kazakh speakers holding accredited university degrees in Kazakh Philology ($N=4$), Computer Science ($N=2$), and Journalism ($N=2$). All annotators completed a 20-hour intensive training workshop focusing on Kipchak morphotactics, formal propositional logic, and Wikipedia sourcing standards.

\subsection{Calibration Phase and Gold Standard Test}
Prior to production annotation, each annotator was evaluated on a 50-claim calibration set featuring pre-adjudicated edge cases. A minimum accuracy threshold of 90\% on the calibration set was required for participation.

\subsection{Double-Blind Annotation and Inter-Annotator Agreement}
A stratified random sample of 20\% of all claims ($N = 600$) was assigned to two independent annotators under strict double-blind conditions. Inter-annotator agreement was evaluated using Cohen's kappa coefficient:
\begin{equation}
\label{eq:cohens_kappa}
\kappa = \frac{P_o - P_e}{1 - P_e}
\end{equation}
where $P_o = 0.893$ is the observed proportional agreement and $P_e = 0.331$ is the expected chance agreement under 3-class distribution. The evaluation yielded:
\begin{equation}
\kappa = 0.840
\end{equation}
indicating strong inter-annotator consensus. Disagreements occurred primarily on scalar modifiers (e.g., whether \textit{``ірі қала''} [large city] requires explicit population thresholds) and multi-hop co-reference chains.

\subsection{Expert Adjudication Panel}
All discrepant claims from the double-blind phase, as well as claims flagged with confidence score $< 4/5$ during single annotation, were submitted to an expert adjudication committee chaired by Dr. Irina Ualiyeva. The committee held weekly consensus sessions to resolve contested interpretations and update the formal guidelines.

\section{Formal JSON Dataset Schema and Field Specifications}
\label{sec:app_fever_schema}

The Kazakh-FEVER 3K benchmark is distributed in JSON-Lines (\texttt{.jsonl}) format. Below is the formal JSON Schema specification adhering to Draft-07 standards:

\begin{small}
\begin{verbatim}
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "KazakhFEVERInstance",
  "type": "object",
  "required": [
    "id", "claim", "label", "evidence_ids",
    "evidence_sentences", "adversarial_flag", "morpho_diagnostics"
  ],
  "properties": {
    "id": {
      "type": "integer",
      "description": "Unique integer identifier for the benchmark claim [1..3000]."
    },
    "claim": {
      "type": "string",
      "description": "The natural language Kazakh claim to be verified."
    },
    "label": {
      "type": "string",
      "enum": ["SUPPORTS", "REFUTES", "NOT_ENOUGH_INFO"]
    },
    "evidence_ids": {
      "type": "array",
      "items": { "type": "string" },
      "description": "List of passage sentence IDs serving as gold evidence."
    },
    "evidence_sentences": {
      "type": "array",
      "items": { "type": "string" },
      "description": "Raw surface text of the cited gold evidence sentences."
    },
    "adversarial_flag": {
      "type": "boolean",
      "description": "True if synthesized under the Hard NEI adversarial protocol."
    },
    "perturbation_type": {
      "type": ["string", "null"],
      "enum": [null, "entity_swap", "temporal_drift", "polarity_flip", "evidential_shift"]
    },
    "morpho_diagnostics": {
      "type": "object",
      "required": ["negation_flag", "temporal_conflict", "numeral_divergence", "evidential_type"],
      "properties": {
        "negation_flag": { "type": "boolean" },
        "temporal_conflict": { "type": "boolean" },
        "numeral_divergence": { "type": "boolean" },
        "evidential_type": { "type": "string", "enum": ["direct", "indirect_hearsay", "neutral"] }
      }
    },
    "annotator_id": { "type": "string" },
    "adjudicated": { "type": "boolean" }
  }
}
\end{verbatim}
\end{small}
